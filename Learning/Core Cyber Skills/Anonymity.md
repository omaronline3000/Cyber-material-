

## **Anonymity vs Privacy**

- `Privacy` -> I know you, but I do not know any thing about you *(your data and info is private)*
- `Anonymity` -> I do not know you *(Your identity is anonymous)*

# Famous OSes

- Whonix and Tails OS 
	- the both linux distros , they shared in anonymity both saves your privacy and make you anonymity using many methods like the both use Tor network by default, and it is hard to trace you
	- the both has differences like Tails OS is a live operating system you can run it using USB and when you shutdown it , the device will forget everything but it does not supported by VMs , not like Whonix which supported by Virtual Box (because it open source)
