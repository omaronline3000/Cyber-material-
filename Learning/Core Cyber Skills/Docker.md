

- Docker is a container, that pull image of a software from `Docker Hub`, and run it on your machine without your machine be qualified to run it 
	- for example you want to run a specific app, that need python and node JS and mysql, and you have not theses on your machine, so install docker and pull an image of this software if it exits on `Docker Hub` , and run it
- it called `container` it is `sandbox` meaning it's isolated from your OS, it like a small server inside your OS, and it type of virtualization types
- the container has its RAM and maybe its IP, it just use the Kernel of your OS
	- and it can run many Images
