
- Windows PE (preinstallation environment)
	- is a light version of windows, not a full OS, run from *Ram, CD, USB, Network* 
		- used for :
			- recovery & restore 
			- windows setup use it before copying the files of the actual OS
			- troubleshooting
			- Disk management
	* it mainly use command line, but it supports some GUI
	* it's reboot every 72 hour
